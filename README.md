# Weather Brief

## Goal
A command-line tool that tells me whether I need an umbrella or a jacket today.

## MVP Scope
- Fetch and cache today's forecast
- Parse high, low, rain chance, and wind
- Print a plain-English recommendation

## Future Plans (V2.0+)
- Morning email/text summary via cron
- Multi-day outlook
- Multiple saved locations
- Severe weather alerts

## Tech Stack
Bash, curl, jq, awk, cron; JSON/text file storage; Open-Meteo API (no key).
